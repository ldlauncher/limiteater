# 🪲 Жук-Лимитоед: AI Тамагочи (iOS 15+ & Web)

> **«Мой Говорящий Жук» — вирусный тамагочи нового поколения!**  
> Питомец, который живёт в твоем телефоне, питается токенами, требует вовремя сбрасывать кэш и показывает свои капризы прямо в виджетах iOS.

---

## 🚀 Как запустить прямо сейчас на компьютере?

В проекте уже готов **полноценный интерактивный веб-прототип игры** с поддержкой мыши, тач-скрина, звуков Web Audio и генератора чеков:

1. Открой файл **`index.html`** в любом браузере (Chrome, Edge, Safari, Firefox).
2. Играй, корми жука, укладывай спать, мой его линтером и фарми токены в аркадной мини-игре!

---

## 🏠 Комнаты в стиле «Говорящего Тома» (My Talking Tom)

В игре сделана классическая нижняя панель навигации по 5 ключевым комнатам:

| Комната | Механика | Что происходит? |
|---|---|---|
| 🍽️ **Кухня** | **Кормление токенами** | Кормим жука *Промпт-печеньем*, *JSON-Бургером*, *Шаурмой 429* или *API Ключом Pro*. Жук смачно чавкает и восстанавливает сытость. |
| 🚽 **Туалет (Кэш)** | **Garbage Collection** | Когда переполняется стек и память, жмем *"Смыть кэш (rm -rf node_modules)"* — слышен звук смыва, память сброшена! |
| 🧼 **Ванная (Линтер)** | **Дебаггинг и чистота** | Жука закидывает багами и мусором — моем его губкой с линтером и мыльной пеной до блеска чистого кода! |
| 🛏️ **Спальня** | **Сон и Day/Night цикл** | Рубильником выключаем сервер: жук надевает ночной колпак, пускает пузыри `Zzz...` и восстанавливает энергию. Утром жмем *"Доброе утро!"* и получаем утренний бонус токенов! |
| 🕹️ **Фарм (Игровая)** | **Мини-игры и Вирус** | Играем в аркаду *"Ловец токенов"*, уворачиваемся от багов и генерируем вирусные счета от Anthropic/OpenAI! |

## 💥 Вайральные (вирусные) фичи игры

1. **🧾 Штрафной счёт от Anthropic / OpenAI**:
   * Генератор реалистичного чека с печатью *«ОПЛАЧЕНО НЕРВАМИ»*.
   * *"Клиент сожрал токенов на $420.69 USD. До сброса лимитов 3 часа"*.
   * Кнопка моментального шеринга в Telegram, Twitter или Stories.
2. **🪲 Ферма Жуков (Multi-pet)**:
   * Выращивай сразу нескольких жуков с уникальными именами (*«Клодик»*, *«Кёрсорик»*, *«Олламыч»*, *«Джипити»*).
3. **📱 Виджеты для iOS 15+ (WidgetKit)**:
   * **Small Widget**: Личико жука, его текущее настроение и полоска голода.
   * **Medium Widget**: Полный статус со всеми 4 потребностями и язвительными цитатами (*«Ты опять сделал запрос к БД в цикле?»*).

## 📦 Сборка `.ipa` для iPhone через GitHub (Без Mac!)

В проект уже добавлен готовый скрипт **GitHub Actions** (`.github/workflows/build_ios.yml`).

### Инструкция:
1. Создай репозиторий на [GitHub](https://github.com/).
2. Отправь код в репозиторий:
   ```bash
   git add .
   git commit -m "feat: Initial Limiteater Tamagotchi"
   git remote add origin https://github.com/твой-логин/limiteater.git
   git push -u origin main
   ```
3. Перейди во вкладку **Actions** в твоем GitHub репозитории.
4. GitHub бесплатно запустит сборку на виртуальной машине macOS.
5. После завершения скачай готовый **`Limiteater-iOS-IPA`** из раздела **Artifacts**.

### Установка на iPhone (Windows):
* Скачай бесплатную программу **Sideloadly** или **AltStore** на свой ПК с Windows.
* Подключи iPhone по кабелю к компьютеру.
* Перетащи скачанный `.ipa` файл в Sideloadly, введи свой Apple ID и нажми **Start**.
* Приложение появится на рабочем столе твоего iPhone!
